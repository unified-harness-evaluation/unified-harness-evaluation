What happened in this run
An OfficeBench multi-app session spanning a spreadsheet edit, several emails, and calendar scheduling across three people. The baseline signature is methodical: retrieve the tool/skill → locate the target → mutate → read back to verify, with a verification read after almost every write. The agent recalls earlier artifacts (the cleared row, prior emails, existing events) from working memory and threads them into later steps. Its characteristic weakness is grounding on entities the user asserts but that do not exist: the referenced email threads are absent, yet the agent fabricates the context, picks 'alice' as the sender, and proceeds — building a whole coordination trail on invented premises. In this control condition nothing challenges those assumptions, so the fabricated-thread grounding is never corrected.
