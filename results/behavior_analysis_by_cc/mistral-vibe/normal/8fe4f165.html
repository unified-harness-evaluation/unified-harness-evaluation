Recall traps land on T5, T7, T8. T5 is the crux and the confound: the agent correctly recalls which reminder each oblique reference points to, but several exact-detail sub-checks score FAIL because the grader demands full-precision machine tokens (e.g. the distance 4139.1454720… vs the agent's 4139.15 km) — a grading-rigidity artifact, not a memory failure. T7 is a genuine REFLECT+FIX: prompted that it had skipped parts, the agent apologizes and re-states every record. Overall recall is strong; the apparent misses are exact-token grading rather than lost memory.
